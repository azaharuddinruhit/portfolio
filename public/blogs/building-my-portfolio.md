Welcome to my first blog post! In this post, I want to talk about how I built this space.

## The Tech Stack

I chose to build this portfolio using a modern frontend stack:
- **React** (with Vite for fast builds)
- **Tailwind CSS** (for styling)
- **Framer Motion** (for smooth animations)

### Why Vite over Create React App?

Vite provides a significantly faster development experience. The hot module replacement (HMR) is almost instantaneous, which makes tweaking styles a breeze.

## Design Philosophy

I aimed for a **dark theme** by default, using a slightly muted teal accent color to give it a "hacker" but professional vibe. The use of monospace fonts in certain areas reinforces the developer aesthetic.

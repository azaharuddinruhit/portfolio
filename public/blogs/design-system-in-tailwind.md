Tailwind CSS isn't just a collection of utility classes; it's an engine for creating design systems.

## The config file

Your `tailwind.config.js` is the heart of your design system.

- **Colors**: Define semantic color scales (e.g., primary, secondary, muted, accent).
- **Typography**: Setting consistent fonts.
- **Spacing**: Keep your layout rhythmic.

By extending the default theme, you ensure that every developer on your team uses the exact same hex codes and spacing values without constantly checking a Figma file.

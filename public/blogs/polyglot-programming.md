
Exploring the syntax and features of multiple programming languages including Java, Go, Kotlin, and Python.

## Java
Java is a class-based, object-oriented programming language.
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

## Go
Go (Golang) is a statically typed, compiled language designed for simplicity and efficiency.
```go
package main
import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

## Kotlin
Kotlin is a modern, cross-platform language that is fully interoperable with Java.
```kotlin
fun main() {
    println("Hello, Kotlin!")
}
```

## Python
Python is an interpreted, high-level programming language known for its readability.
```python
def greet(name):
    print(f"Hello, {name}!")

if __name__ == "__main__":
    greet("Python")
```
